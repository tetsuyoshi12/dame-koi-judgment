# ペルソナ定義

## Persona 1: 佐藤 健斗（さとう けんと）— メインペルソナ

**属性**
- 年齢: 32歳
- 職業: 都内IT企業 プロダクトマネージャー
- 婚活歴: アプリ利用8ヶ月、課金額累計10万円以上

**婚活の悩み**
- 書類審査（マッチング）の通過率が極端に低い
- マッチしても会話が3往復で終わる
- 何ヶ月も成果が出ず、わらにもすがる思いでAIアドバイスを求めている

**現在の虚飾（鎧）**
- 自己紹介：「週末はカフェ巡りやジムでリフレッシュ」「互いに高め合える関係が理想」
- 趣味記述：「読書、映画鑑賞、新しいレストランの開拓」など意識高い系の羅列

**裏の顔（素顔）**
- 実際は休日カップ麺とYouTube
- ジムは月1回
- 仕事のプレッシャーで疲弊しており、本音は「何もしたくない」

**このサービスに来る動機**
- 「AWSの最新AIがプロフィールを論理解析」という知的な建付けに惹かれる
- 表向きは「改善」を求めて来るが、実は「もう頑張らなくていい」というお墨付きを求めている
- PMとしてロジック・エビデンス重視の世界の住人なので、論理的な否定に最も逃げられない

**感情の弧**
`自信（虚飾）` → `動揺（論理的否定）` → `諦め（頑張るのをやめる）` → `期待（ダメなまま勝てる新戦略）`

## Persona 2: 田中 美咲（たなか みさき）— サブペルソナA

**属性**
- 年齢: 28歳
- 職業: 大手商社 営業職
- 婚活歴: アプリ利用6ヶ月、複数アプリ掛け持ち中

**婚活の悩み**
- マッチング数は多いが、会うと「思ってたのと違う」と言われる
- 「明るくて社交的」なキャラを演じ続けることに疲れている
- 本当は家でゴロゴロしたいのに、アクティブ女子を演じている

**現在の虚飾（鎧）**
- 「週末はアウトドアや友人とのランチが多いです」
- 「仕事もプライベートも全力で楽しむタイプです」

**裏の顔（素顔）**
- 休日は昼まで寝てNetflixを一気見
- 友人との予定は月1回あれば多い方
- 「一緒にダラダラできる人」が本当の理想

**このサービスに来る動機**
- 「演じることに疲れた」という感覚が強く、「ありのままでいい」という言葉に惹かれる
- 論理的な否定よりも「共感」を求めているが、結果として論理に納得する

## Persona 3: 鈴木 拓也（すずき たくや）— サブペルソナB

**属性**
- 年齢: 35歳
- 職業: フリーランス エンジニア
- 婚活歴: アプリ利用1年以上、マッチング数が極端に少ない

**婚活の悩み**
- そもそもマッチングが取れない（書類審査の壁）
- 「趣味：プログラミング、アニメ、ゲーム」と正直に書いたら全滅
- 「盛ればいいのか、正直に書けばいいのか」で迷走中

**現在の虚飾（鎧）**
- 「最近はアウトドアにも興味があります」（実際は一度も行ったことがない）
- 「料理も好きです」（インスタント麺しか作れない）

**裏の顔（素顔）**
- 週末はゲームと技術書で完結
- 料理は電子レンジのみ
- 「同じ趣味の人と静かに過ごしたい」が本音

**このサービスに来る動機**
- 「正直に書いても盛っても上手くいかない」という行き詰まり感
- AIによる「第三の道（ダメなまま勝つ）」への期待
- エンジニアとして技術的な建付けに親近感を持つ
